# Security, performance and network audit, 2 Nov 2026

Branch `fix/launch-audit`. Everything below was measured on the **local QA build** (port 3500, the scrubbed QA database on 5435, test accounts only). Nothing was sent to staging or production. Lighthouse numbers are Lighthouse's simulated slow-4G mobile profile, so they are for comparing, not for promising.

**Verdict:** no exploitable hole found. Four hardenings and one dependency fix are done and tested. The rest are owner decisions, listed at the end.

## What was fixed

| # | Area | Finding | Fix | Proof |
|---|---|---|---|---|
| 1 | Security (low) | HTML sanitizer: an unterminated tag at the end of a body (`<img src=x onerror=…`) was passed through verbatim. Browsers drop it at end of input, but joined to more HTML it would become a live tag. | Any `<` that is not an allowlisted tag becomes `&lt;` (`STRAY_LT`, `src/lib/richtext.ts`). | I ran a 48-payload corpus by hand; 23 hostile payloads are now pinned in `richtext.test.ts`, plus tests for this case. |
| 2 | Security (low) | `//host`, `/\host` and `/<TAB>/host` passed the "starts with /" href rule, so a pasted job description could carry an unmarked external link. | `SAFE_HREF` refuses a second `/` or `\`; control characters are stripped before the check. | Tests with tab, LF, CR variants. |
| 3 | Security (defence in depth) | `GET /api/admin/support-file/[key]` (reads any stored file by key) and `GET /api/admin/google/connect` had no check inside the handler and relied only on the proxy. | `requireRole(cookie, ["admin"])` in both. | New test fails when an `/api/admin` route has no guard call of its own (a `require*` helper, or a session read plus an explicit `role !== "admin"` check). It matches names, not behaviour. I reverted the two routes once to confirm it names them. |
| 4 | Security (moderate advisory) | `npm audit`: nodemailer address-parser issues (a crafted address can add a recipient). | `nodemailer ^10.0.14 → ^10.3.1`, lockfile changes only that package. | `npm audit --omit=dev`: 0 vulnerabilities. |
| 5 | Performance | Admin and employer dashboards downloaded gsap and ScrollTrigger (about 130 KB raw) although only marketing pages use them: `SmoothScroll` sat in the root layout. | `SmoothScroll` moved into the marketing layout. This also fixes the college console, which was never on its exclusion list. | Admin 910 → 780 KB, employer 904 → 774 KB raw JS per dashboard. |
| 6 | Performance | The intern dashboard still loaded gsap: its FAQ link, the "Contact us" menu entry and the "How the 18-month guarantee works" tile link are prefetched, and those marketing pages bring gsap with them. | `prefetch={false}` on those three (`ConsoleNavItem`, `ConsoleMenuLink`, `Tile` action). | Intern dashboard JS: 1016 → 828 KB raw. |
| 7 | Network | Blog covers were served at 1600 px to every device (about 346 KiB avoidable on the blog page, Lighthouse). | `?w=` on `/api/blog-image` and `/api/cms-image` from an allowlist (96, 192, 480, 800, 1600); `srcset` on blog cards, post hero and related thumbnails. | `?w=480`: 50 KB → 13 KB. Unlisted widths fall back to the default, so the query cannot force arbitrary resizes. |

## Owner decisions and open items (not changed)

1. **Production `PUBLIC_ORIGIN` must be `findtern.in` or `www.findtern.in`.** Any other host (for example `app.findtern.in`) makes the whole site `noindex` and `Disallow: /`. `TRUST_PROXY=1` must also be set (launch checklist A5), or every visitor shares one rate-limit bucket.
2. **CSP is report-only and allows `'unsafe-inline'` scripts.** It blocks nothing today. Enforcing it needs nonces and a staging run that reads `/api/csp-report`.
3. **Per-account guessing from many addresses is not limited**: the key is address + email (QA-138 chose that so a campus lab is not locked out together). A separate, higher per-email ceiling would close it, at the cost of letting someone lock a victim out. Passwords are argon2-hashed.
4. **Indexes.** The QA copy has none on `proposals`, `interviews`, `projects`, `intern_onboarding.user_id` or notifications by recipient, and none on `timesheets.employer_id`. At today's row counts (6 proposals, 94 notifications) it costs nothing measurable, so I did not ship a migration. Worth a migration `0009` before the tables grow; it needs the usual rehearsal.
5. **Public phone lookup** (`users/exists/phone`) tells anyone whether a number is registered. Rate-limited; a normal sign-up trade-off.
6. **Still open from 1 Nov:** B2 (Google-created accounts have no password; decide `GOOGLE_LOGIN=on` at cutover), B3 (remove the test-pay button in launch week), M7's second half (hires with no monthly payment on file cannot be paid online), M8 (accepting an offer expires the intern's other offers), F1 (production Postgres reachable from the internet; not checked here).
7. **Not done, low value:** 18 raw `<img>` tags outside the blog; `/admin/reports/money` payload; brotli.
