## Component Selection Guidelines
- **Watermelon Primitives First**: Used for state transitions, animated status pickers, segmented discrete tabs, and micro interactions.
- **shadcn via Watermelon MCP**: Used for structural primitives including data tables, slide over sheets, dialog modals, dropdown menus, and command palettes.
- **No Guessing**: All APIs and props match the verified registry definitions from `https://registry.watermelon.sh/r/<name>.json`.
